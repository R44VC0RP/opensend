### Top 10 to simplify or remove first

1. **`WEBHOOK_ALLOWED_HOSTS` env allowlist** — Remove the env var (which is `""` on MX and currently blocks every MX webhook) and enforce public HTTPS + self-origin denylist + private-IP SSRF checks instead.
2. **Duplicate `/mailbox/v1/*` API and `mailbox`/`address` aliasing** — Delete `/mailbox/v1/*` and event/catch-all name translation, leaving `/v1/inbound/*` as the sole inbound surface.
3. **`publicAddress` local-part/parent-domain rule and asymmetric reply `from`** — Allow any verified workspace domain/address authorized by the caller's key as `from` or `defaultFrom`, regardless of local part or credential type.
4. **Mandatory `confirm: true` parameter on MCP tools** — Drop `confirm` from MCP tool schemas (especially POST previews) and rely on OAuth `read`/`send`/`manage` scopes.
5. **`replyAddressId` / `replyMailboxId` bridge on `POST /v1/emails/send`** — Remove both fields and use `POST /v1/inbound/threads` to start tracked conversations.
6. **Per-address `sendLimits` overrides and `ttlSeconds` temporary leases** — Keep fixed loop-guard defaults in code and use ordinary address creation/deletion instead of expiring reservations.
7. **Opt-in Jev spam screen (`screen` / `JEV_*`) and `REPUTATION_ALERT_SLACK_URL` engine** — Screen untrusted text in the calling app before `sendEmail` and emit standard webhook events instead of running a bespoke classifier/Slack bot inside OpenSend.
8. **Hardcoded `firstName | plan | country` segment/CSV fields and `AudienceQL`** — Allow any `properties.<key>` in JSON `SegmentRule` and CSV mappings, and remove the custom SQL parser and 15-minute plan tables.
9. **Separate `/v1/webhooks` and `/v1/inbound/webhooks` stacks** — Merge `inbound.*` events and optional `addressIds` filtering into `/v1/webhooks`.
10. **Four credential types (`api_keys`, `mailbox_keys`, `agent_tokens`, `mcp_`) and dual MCP servers** — Consolidate machine tokens into `api_keys` (scopes + optional `domains`, `addressIds`, `expiresAt`), accept them directly on `/mcp`, and remove `mcp/src/server.ts`.
